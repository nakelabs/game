Place custom external assets in this folder to override the built-in cel-shaded Canvas vector graphics:

- `story.mp4` — Intro cutscene video played fullscreen when clicking "START DELIVERY"
- `player_bike.png` — Top-down player dispatch motorcycle sprite
- `danfo.png` — Lagos yellow Danfo bus obstacle sprite
- `keke.png` — Keke Napep tricycle obstacle sprite
- `barricade.png` — Roadblock barricade obstacle sprite

If any of these files are omitted, the application automatically falls back to high-detail cel-shaded Canvas vector art and transitions seamlessly into the game.
